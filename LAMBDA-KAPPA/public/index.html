🎯 Bảng Đánh Giá Đặc Tính Chất Lượng Thực Tế (Quality Attributes)

1. Performance (Độ trễ xử lý dòng thời gian thực) PASSED

• Chỉ số đo: Stream Latency: 12ms (Tiêu chuẩn: ≤ 1000 ms).

• Công cụ: Flink Web UI / Prometheus Metric API.

2. Reliability & Accuracy (Độ chính xác và tính nhất quán) CONSISTENT

• Độ lệch nhất quán: Δ = |Master − Aggregated| = 0.

• Cơ chế: Batch Layer tính toán lại định kỳ trên Master Dataset bất biến để khử sai lệch.

3. Scalability (Khả năng chịu tải dữ liệu lớn - Big Data) Locust Benchmark

• Chỉ số đo: Throughput ≥ 10,000 events/giây với cụm phân tán.

• Công cụ kiểm thử: Locust Load Testing Tool.

4. Recomputability & Exactly-Once (Tái tính toán khi đổi logic) Kappa Replay

• Cho phép Replay lại toàn bộ luồng sự kiện từ Offset 0 mà không làm mất dữ liệu gốc.

⚡ Đối Chiếu Trực Tiếp: Lambda Serving vs SQL Full-Scan

🏛️ Kiến trúc Lambda (Merge View):

• Độ trễ: Chưa đo

• Độ phức tạp: O(1) Constant Time

• Đánh giá: Không bị chậm khi DB lớn

🐢 Quét Full-Scan Truyền thống:

• Độ trễ: Chưa đo

• Độ phức tạp: O(N) Linear Time

• Đánh giá: Chậm và nghẽn khi dữ liệu lớn

🦗 Hướng Dẫn Chạy Kiểm Thử Tải Bằng Locust (Load Testing)

Công cụ Locust đã được cài sẵn trên máy bạn tại /opt/homebrew/bin/locust.

1. Chạy Locust Web Dashboard (Mở giao diện biểu đồ RPS):
cd /Users/apple/KTPM/LAMBDA-KAPPA
locust -f locustfile.py --host http://localhost:5050
2. Mở trình duyệt để xem biểu đồ tải & RPS:
http://localhost:8089
3. Hoặc chạy test tự động dòng lệnh (Headless Mode):
locust -f locustfile.py --headless -u 50 -r 10 --run-time 20s --host http://localhost:5050
💡 Mẹo thi vấn đáp: Khi chạy lệnh locust, hãy mở http://localhost:8089 nhập 50 Users và chụp lại biểu đồ Total Requests per Second (RPS) và Response Time (ms) để làm minh chứng thực tế cực kỳ thuyết phục!
