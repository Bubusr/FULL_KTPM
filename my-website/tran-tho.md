# Trần Thọ

Đây là trang cá nhân của Trần Thọ.

## 👨‍💻 Thông tin cá nhân & Vai trò dự án
- **Họ và tên:** Trần Thọ
- **Vai trò:** Kỹ sư tích hợp API & Bảo mật hệ thống (APIs & Security)
- **Đề tài nghiên cứu:** Cơ chế giao tiếp Serverless APIs và đánh giá an toàn thông tin trên kiến trúc JAMstack

## 🎯 Đóng góp chính trong dự án
- Tích hợp kết nối GitHub REST API để nạp dữ liệu Profile và Repository động phía máy khách.
- Xây dựng module Form phản hồi không máy chủ (Serverless Feedback Endpoint).
- Đánh giá và kiểm thử bảo mật Security Headers (HSTS, X-Frame-Options, triệt tiêu SQL Injection).
